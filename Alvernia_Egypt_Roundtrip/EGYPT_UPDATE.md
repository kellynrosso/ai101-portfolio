# Egypt update
Starts near the Pyramids of Giza. Location buttons also jump to the Valley of the Kings and the Egyptian Museum in Tahrir Square, Cairo. Pins are approximate landmark viewpoints, not entrances.
Satellite map: Esri World Imagery via Cesium UrlTemplateImageryProvider, with attribution shown in the viewer. No Cesium ion token needed for this imagery layer. Internet access required; choose Grid view if imagery is unavailable. Satellite imagery does not supply detailed 3D terrain or buildings.
The Slow Observation feature and original movement tests are retained. Reset now returns to the selected landmark. Earlier draft documentation/evidence describes the original Reading grid version and is historical; recheck manual tests and update your reflection for this Egypt version.
## Upload
Unzip, then drag the entire Flight_Lab folder onto the GitHub upload page at the repository ROOT. Commit to replace matching Flight_Lab files. Do not upload into the existing Flight_Lab folder, which would nest it. Refresh the live site after publishing.
## Checks to perform in browser
Visit each of the three locations; confirm scenery and label. Fly, pause, turn, change speed/height, and reset. Confirm reset returns to the selected location. Switch Satellite/Grid. Open tests.html.
