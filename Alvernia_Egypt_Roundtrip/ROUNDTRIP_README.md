# Alvernia–Egypt round trip
Separate version of Flight Lab. Start round trip follows four Cesium geodesic legs: Alvernia Student Center vicinity → Giza → Valley of the Kings → Egyptian Museum (Tahrir) → Alvernia. 35/20/20/35 seconds per leg; six-second stops in Egypt. About 128 seconds total at smooth frame rates. Pause/Fly pauses/resumes; Return to Alvernia cancels and returns home. Location buttons cancel the trip and jump to their viewpoint.
Travel is accelerated and schematic, not an airline route or real flight-time estimate. Satellite imagery on a smooth globe, no detailed 3D buildings.
Alvernia coordinates 40.309705, -75.938187 come from the camera location of a Student Center photo, and are explicitly approximate. Source: https://commons.wikimedia.org/wiki/File:Student_Center_at_Alvernia_University.JPG
Campus context: https://www.alvernia.edu/about/locations/alvernia-universitys-reading-locations
Geodesic API: https://cesium.com/learn/cesiumjs/ref-doc/EllipsoidGeodesic.html
